1 架构与页面路由 基础

本平台为纯前端 SPA 风格多页面应用，页面间通过 window.location.href 跳转，登录态持久化在 localStorage。

1.1 页面路由表

路由文件页面名称登录态要求角色要求未满足时行为
login.html登录/注册页未登录—已登录用户访问 → 自动跳 dashboard.html
dashboard.html工作台首页必登录—未登录 → login.html；登录超 7 天 → login.html
role-auth.html角色认证页必登录—同上
requirement-form.html发布需求表单必登录—同上

1.2 登录态校验逻辑

// 每个受保护页面在 <script> 顶部执行
var user = JSON.parse(localStorage.getItem("opc_user") || "null");
if (!user) {
  window.location.href = "login.html";
}
// 登录态过期：7 天 = 7 * 24 * 60 * 60 * 1000 ms
var EXPIRE_MS = 604800000;
if (Date.now() - user.time > EXPIRE_MS) {
  localStorage.removeItem("opc_user");
  window.location.href = "login.html";
}
⚠ 开发者注意 user.time 是登录时写入的 Date.now() 毫秒时间戳。过期后必须 先 removeItem 再跳转，否则用户回退时仍能访问受保护页面。

附录 B — 校验正则汇总

// 手机号
/^1[3-9]\d{9}$/

// 密码：≥6 位 + 含大写 + 含小写 + 含符号（非字母数字）
/(?=.*[a-z])(?=.*[A-Z])(?=.*[^a-zA-Z0-9])/

// 身份证号：18 位，最后一位可为 X
/^\d{17}[\dXx]$/

// 统一社会信用代码：18 位（排除 I O S Z）
/^[0-9A-HJ-NPQRTUWXY]{18}$/

// 联系方式打码：数字 → *
contactInfo.replace(/\d/g, "*")

// 需求标题字数统计：中英文各计 1
title.length  // 直接用 length，1 个汉字 = 1，1 个英文字母 = 1
