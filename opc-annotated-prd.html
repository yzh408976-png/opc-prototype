📋 OPC 需求平台 — 原型标注文档

本文档基于 Axure 原型标注模式，对平台四个核心页面进行逐元素编号标注与旁侧批注，面向开发与设计团队。

📌 阅读方式 每个页面标注区分为左右两部分：左侧为页面可视化截图（红色编号标记对应关键元素），右侧为旁侧批注面板（编号与标记一一对应，含字段约束、交互逻辑、错误提示）。点击右侧批注项可高亮对应标记。

产品概述

产品介绍

OPC 需求平台是一个面向企业需求方与 OPC 服务者的需求发布与匹配平台。企业用户可结构化发布需求（基本信息、需求参数、联系信息），系统据此匹配具备对应能力标签的 OPC 服务者，完成撮合交易。

产品用户

角色描述核心诉求
企业需求方有外包/协作需求的企业用户快速发布需求、获得匹配、管理进度
OPC 服务者提供专业服务的个人/团队浏览需求、接单、交付成果
超级管理员平台运营人员审核认证、管理用户、监控平台

6协议勾选
必勾 未勾选时提交拦截，提示「请先同意用户协议和隐私政策」。
7提交按钮
全宽蓝色圆角按钮。登录模式文字「登录」，注册模式文字「注册」。成功后存入 opc_user 并跳转工作台。
8模式切换链接
登录模式：「还没有账号？立即注册」。注册模式：「← 返回登录」（蓝色边框按钮样式）。点击切换 isRegMode。
9第三方登录
微信、GitHub、Google 三个圆形按钮。点击 toast 提示「即将上线」，当前为装饰按钮。
10拼图人机验证
点击获取验证码触发。拖动滑块对齐拼图块，容错 ±6px。通过后 600ms 关闭 + 开始倒计时；失败 800ms 后重置。
11密码可见切换
密码框和确认密码框各有 👁/🙈 切换。输入框 padding-right:42px 防重叠。已禁用浏览器原生 ::-ms-reveal。
12注册模式额外字段
注册时在密码下方显示：手机号输入框 + 确认密码输入框。CSS 类 .reg-only 控制显隐。确认密码需与密码一致。

1步骤条
三步：① 选择角色 → ② 填写认证 → ③ 确认提交。当前步骤黑色圆圈，已完成绿色 ✓，连接线完成后变绿。管理员登录时整个步骤条 hidden。
2角色选择卡片
OPC 服务者（绿色边框）+ 企业需求方（橙色边框）。点击展开对应认证表单，步骤条进入 Step 2。
3OPC 认证表单
8 个必填字段：真实姓名、手机号、身份证号（18位正则）、所在城市、擅长领域（下拉选择）、个人简介（选填）、接单状态（单选）、身份证正反面。

5管理员直通卡片
role === "admin" 时显示紫色卡片，隐藏角色选择和步骤条。点击「进入工作台」直接跳转 dashboard.html。
6企业认证字段
10 个必填字段：企业名称、统一社会信用代码（18位正则 /^[0-9A-HJ-NPQRTUWXY]{18}$/）、行业、规模、城市、地址（≥5字）、联系人、电话、营业执照正副本。
7角色徽章
右上角统一显示。管理员紫色「超级管理员」，OPC 绿色「OPC 服务者 / 认证中」，企业橙色「企业需求方 / 认证中」。点击跳转认证页。
8提交认证
校验所有必填项，失败时 toast 提示对应字段。成功后存入 opc_role（含 type/status/data），步骤条进入 Step 3，跳转工作台。
9返回按钮
填写认证阶段可点「返回」回退到 Step 1 重新选择角色。已填写的表单数据保留。
10营业执照上传
企业认证时显示。左右并排：正本 + 副本。分别校验，分别提示缺哪个。
11擅长领域
下拉单选（非多选），选项含文案创作、设计创意、技术开发、数据分析等方向。非默认占位时通过校验。

1左侧毛玻璃导航栏
240px 宽，backdrop-filter: blur(16px)。含 Logo + 导航菜单（含三个分区锚点）+ 用户卡片 + 退出按钮。移动端隐藏。
2顶部操作栏
5 个按钮：① 提交需求（蓝色主按钮）② 预览 ③ 保存草稿 ④ 导入模板 ⑤ 填写设置。
3① 基本信息分区
含需求标题、任务描述（+附件）、交付标准（+附件）。三个字段均必填。
4需求标题
必填 maxlength=80，中英文各计 1。右下角实时计数 X/80，≥70 变红。固定常显，不可关闭。
5任务描述 + 附件
必填 引导文案：业务背景、目标、任务范围、输入资料、限制条件。下方有「📎 插入附件」按钮，支持图片和文档多选。
6交付标准 + 附件
必填 引导文案：最终交付物、格式、数量、验收标准、返修规则。同样有附件按钮。
7② 需求参数分区
含预算范围、期望周期、付款方式、远程协作、能力标签。全部必填。
8预算范围
必填 数字输入，≥0。填 0 = 面议。
9期望完成周期
必填 日期选择器，用于判断任务紧急程度和 OPC 排期。
10付款方式
必填 下拉选择。枚举：一次性付款 / 按里程碑 / 按小时 / 面议。
11远程协作
必填 下拉选择。枚举：支持远程 / 需到场 / 混合。
12OPC 能力标签
必填 ≥1 关键词搜索过滤，点击添加为芯片，逐个可移除。系统据此同步预算和交付标准预设。
13③ 联系信息分区
含联系人/部门、联系方式。两个必填字段。
14联系人/部门
必填 length ≥ 2，错误提示「请输入联系人或部门名称」。
15联系方式
必填 可输入手机号/微信/邮箱。预览时数字逐位打码为 *：contactInfo.replace(/\d/g, "*")。非数字字符保留。
16草稿/模板功能
「保存草稿」→ 存入 opc_draft，下次进入弹窗询问恢复。「导入模板」→ 存入 opc_template，点击后询问是否导入。提交成功后自动清除草稿。
17填写设置
3 个开关：自动保存草稿（每30s）/ 提交后保留内容 / （字数统计已移除，固定常显）。状态存 localStorage。
18预览弹窗
点击「👁 预览」弹出。以服务者视角展示需求单：蓝色头部 + 任务描述 + 交付标准 + 需求参数四宫格 + 能力标签芯片 + 联系信息（打码）。支持 × / 返回 / 遮罩关闭。
