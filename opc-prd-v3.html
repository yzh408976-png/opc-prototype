二产品概述
2.1 产品介绍

OPC 需求平台连接企业需求方与 OPC 服务者（One Person Company，个人服务提供者）：企业发布结构化需求，OPC 在抢单大厅浏览、报价、接单并交付，平台提供角色认证、管理员审核、协议管理、停用风控等保障能力。

当前交付物为纯前端高保真原型：无后端，全部数据用 localStorage 模拟（账号表、审核队列、文件表、变更日志），验证码通过 Toast 模拟下发。

用户痛点平台方案
企业需求方找个人服务者成本高、质量不可控结构化发布需求 + 平台认证背书 + 审核准入
OPC 服务者缺稳定需求来源、结算无保障抢单大厅智能匹配 + 平台结算保障

2.5 业务目标

3 个月内跑通「注册 → 认证 → 发布 → 抢单 → 报价 → 交付」最小闭环原型；管理员侧完成准入审核与合规风控能力验证。

四全局说明
4.1 页面路由与登录态
页面文件登录态角色要求不满足时行为
登录/注册login.html未登录—已登录访问自动跳对应工作台
企业工作台dashboard.html必登录企业/管理员未登录跳 login；OPC 用户弹回 opc-dashboard
OPC 工作台opc-dashboard.html必登录OPC企业/管理员弹回 dashboard
角色认证role-auth.html必登录—未登录跳 login
发布需求requirement-form.html必登录—同上
变更日志change-log.html必登录仅管理员非管理员自动跳回工作台
⚠ 登录态规则登录态存 localStorage.opc_user，有效期 7 天（Date.now() - user.time > 604800000 即过期）。过期必须先 removeItem 再跳转 login.html，否则用户回退仍可访问受保护页面。过期后若存在「记住我」记录（opc_remember），自动回填邮箱并勾选记住我，只需重新获取验证码即可登录。
4.2 全局组件规范
组件规范
Toast顶部居中滑入，success 绿 / error 红 / info 蓝；默认 2.5s，注册成功展示账号 ID 的 Toast 为 4s
角色徽章所有页面右上角统一展示：管理员紫 / OPC 绿 / 企业橙 / 未认证灰 / 认证中黄 / 未通过红
未认证遮罩毛玻璃（backdrop-filter 模糊）+ 白色卡片；功能入口 45% 透明度 + pointer-events:none；「角色认证」导航永远可点
身份守卫每个工作台页面加载时校验 authRole，不匹配则 alert 后跳转到对应工作台
状态同步工作台每 3 秒 + 页面聚焦（visibilitychange/focus）时从 opc_accounts 同步 authStatus/authRole/avatar，管理员操作 3 秒内反映到用户端
账号停用accounts[].status = 1 即停用；登录时拦截并提示「该账号已被停用，请联系管理员」
变更日志统一 addLog(user, type, field, desc) 写入 opc_change_logs；type ∈ avatar / profile / auth / status / file
4.3 文件存储（模拟 sys_file）
字段说明
fileId自增主键
fileName原始文件名
filePath模拟 MinIO 路径：认证文件 /uploads/年/月/fileId_文件名；头像 /uploads/avatars/账号ID_fileId_文件名
fileSize字节数；认证文件 ≤10MB，头像 ≤2MB，超限 Toast 拦截
contentTypeMIME 类型；仅允许 jpeg/png/gif/webp/bmp/pdf
uploadUser上传者账号 ID
fileType仅认证文件：id_front 身份证正面 / id_back 反面 / license 营业执照（仅正本）/ qualification 企业资质
五非功能性需求
类别要求
浏览器兼容Chrome / Edge 最新两个大版本；密码框原生 reveal 按钮已用 CSS 隐藏（::-ms-reveal 等），防止与自定义小眼睛重叠
响应式登录页适配移动端（卡片 max-width 400px 居中）；工作台最小适配 1280px 桌面
数据安全（原型）全部数据仅存浏览器 localStorage，清缓存即清空；正式版密码必须 BCrypt 加密、验证码存 Redis 并设置过期时间
性能页面零依赖（仅 Google Fonts 可选），单文件可直接 file:// 打开（跨页登录态需 http 环境）
可用性所有校验错误即时 Toast + 输入框红边，输入即清除错误态；按钮提交中置灰防重复提交
